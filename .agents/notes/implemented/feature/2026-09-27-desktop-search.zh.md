# Agent Note: 桌面版搜索页面

Status: implemented

[English](2026-09-27-desktop-search.md) | 中文

## Problem

Flutter 搜索入口目前提供插画关键词结果和最近搜索记录。Compose 搜索页面还提供小说与用户结果、自动补全、当前账号可用的筛选条件、置顶记录、数字编号识别和 Pixiv 链接识别。这些功能共同组成搜索流程。

## Decision

Flutter 搜索页面提供插画、小说和用户三个结果标签。插画与小说请求使用现有的 Rust 分页列表入口，并由 Dart 标准库的 `Uri` 构造经过编码的查询参数。Rust 通过同一个已登录的 Pixiv 请求客户端提供自动补全、当前账号可用的筛选选项和用户搜索。切换结果标签时，各标签保留已加载的内容。搜索条件使用与 Compose 页面相同的接口参数；客户端还根据 R18 和 AI 选项筛选返回的作品。输入数字编号时，可以选择作品、小说、用户或关键词搜索。Pixiv 链接打开对应的客户端详情页面。搜索记录保留置顶条目，支持删除单条记录或清空任一分组。搜索记录与浏览记录使用 Unix 毫秒时间戳，与现有的 Compose 记录一致。

## Alternatives considered

**保留只有插画的搜索。** 小说和用户搜索仍无法从现有搜索入口使用。

**在 Rust 再实现一套查询参数构造器。** Rust 已有接收请求路径的分页函数，Dart 的 `Uri` 类能够构造经过编码的查询字符串。增加另一套构造器会重复这些工作。

## Consequences

Rust 桥接层提供搜索建议、筛选选项、用户搜索和按分组删除搜索记录。插画与小说摘要包含受限内容和 AI 标记，供当前搜索条件筛选结果。过滤后没有内容的页面继续使用服务端游标，直到找到可见内容或分页结束。

## Verification

使用当前登录状态运行搜索探针，请求自动补全、筛选选项和三类搜索结果，并将数量写入可重复检查的本地产物。使用独立的真实 SQLite 文件验证时间排序、重复搜索、保留置顶和按分组删除。macOS 构建验证搜索页面及生成的 Rust 桥接代码能够编译。
