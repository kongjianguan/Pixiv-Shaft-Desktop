# Agent Note: 桌面版发现页面

Status: implemented

[English](2026-09-27-desktop-discovery.md) | 中文

## Problem

Flutter 发现入口只显示插画排行。Compose 页面还包含热门标签、带模式和日期选项的插画与小说排行，以及 Pixivision 文章。这些入口集中在发现页面，方便用户连续浏览。

## Decision

Flutter 发现入口展示与 Compose 页面相同的内容区块和排行模式。插画与小说排行各自保留模式、日期、分页位置和滚动位置。全局 R18 设置控制可选的排行模式。Pixivision 在发现页面提供文章预览，并有独立的插画与漫画文章页面。文章链接由系统浏览器打开。Rust 核心负责 Pixiv 接口请求和响应转换；Flutter 负责页面状态与呈现。

## Alternatives considered

**保留只有排行的页面。** 其他发现入口无法从原有位置进入，两个桌面客户端的浏览行为也会产生差异。

**在发现页面内展示完整文章列表。** 现有页面使用简短预览和独立文章页面。沿用这个结构可以保留浏览流程，也让文章列表独立分页。

## Consequences

打开发现页面时，客户端请求热门标签、两类排行和文章预览。排行区域在页面滚动视图中保持固定高度，各自独立分页。Rust 图片客户端通过作品图片使用的 CDN 请求链路获取标签和文章封面。

## Verification

使用当前登录状态运行发现页面探针，验证四类首页请求、标签图片和文章封面。macOS 构建验证 Flutter 页面及生成的 Rust 桥接代码能够编译。
