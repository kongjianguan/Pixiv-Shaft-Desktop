# Agent Note: macOS 窗口内容占满高度

Status: implemented

[English](2026-09-27-full-height-window.md) | 中文

## Problem

macOS 标题栏在占满窗口的作品流上方留出一整行空白。Flutter 内容延伸到这一区域后，原生窗口按钮会覆盖 Flutter 控件，因此导航控件和鼠标操作需要明确的安全区域。

## Decision

Runner 启用 AppKit 的全尺寸内容视图和透明标题栏，隐藏标题文字，同时保留原生窗口按钮及关闭窗口后的状态栏行为。推荐作品流从窗口顶端开始显示，紧凑的内容切换控件位于标题栏区域。`macos_window_utils` 提供标题栏高度，并把切换控件的原生鼠标事件传给 Flutter。只有推荐页面处于当前导航页面时，才安装原生鼠标事件传递区域。根部 `MediaQuery` 将测得的顶部安全距离提供给带标题栏的页面。其他主页面按照该距离放置操作控件，推荐作品流则绘制到原生标题栏下方。窗口最小宽度确保居中的切换控件与原生按钮保持距离。

## Alternatives considered

**保留独立标题栏。** 标题栏占用垂直空间，作品流无法使用这一区域，内容切换控件也留在窗口按钮下方。

**完全使用 AppKit 实现内容切换控件。** 这种方式需要复制选择状态，并与 Flutter 页面控制器双向同步。Flutter 控件继续统一管理标签选择状态。

## Consequences

作品图片可以使用整个窗口高度，包括原生按钮后方的区域。搜索、个人、发现、动态、登录及详情页面的操作控件处于标题栏安全区域下方。原生窗口按钮继续负责关闭、最小化和调整窗口大小。进入全屏及调整窗口尺寸时，安全距离随 AppKit 窗口实际尺寸更新。

## Verification

macOS 集成测试检查内容切换控件与实际标题栏区域相交、各标签能够选择，以及登录页标题位于安全区域下方。打包后的应用检查原生窗口按钮、鼠标操作和关闭窗口行为。
