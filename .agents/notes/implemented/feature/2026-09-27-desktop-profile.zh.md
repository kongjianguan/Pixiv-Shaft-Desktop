# Agent Note: 桌面版个人页面

Status: implemented

[English](2026-09-27-desktop-profile.md) | 中文

## Problem

Flutter 个人页面只展示已发表的插画以及收藏接口的第一页。作者页面展示作品，但没有公开收藏入口。这些页面无法浏览后续分页，也无法展示 Compose 客户端已有的个人小说作品。

## Decision

个人插画收藏、小说收藏、已发表插画和已发表小说都通过 Rust 接口读取带游标的分页列表。个人页面保留四个标签，“我的作品”标签提供插画与小说选择。个人资料上方通过已有的用户列表页面提供关注中、粉丝和好P友入口。作者页面提供作品与公开收藏两个标签。退出登录放在设置页面的账号区，用户可以从 macOS 菜单或个人页面进入设置。

## Alternatives considered

**保留只有第一页的列表。** 拥有多页作品或收藏的用户无法浏览较早的内容。

**继续在个人页面顶部放置退出登录。** Compose 客户端将账号操作归入设置页面。两个位置重复放置会增加个人页面的控件。

## Consequences

Rust 个人列表函数同时返回条目和服务端分页游标。个人页面与作者页面使用共用分页网格，也继承空白分页的处理方式。在个人页面保持打开时，切换已发表插画与小说会保留各自加载的内容。

## Verification

使用当前登录状态运行个人页面探针，获取个人资料、头像、两类收藏、两类已发表作品及作者公开收藏。macOS 构建验证个人页面和生成的桥接代码能够编译。
