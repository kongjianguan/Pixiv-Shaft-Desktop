- [ ] **Step 1: Add isFollowing state + sync on load + toggleFollow**

Add to `IllustDetailScreenModel`:

```kotlin
private val _isFollowing = MutableStateFlow<Boolean?>(null)
val isFollowing: StateFlow<Boolean?> = _isFollowing.asStateFlow()
private var _userId: Long = 0
```

In the illust loading method (after `_illustState.value = UiState.Success(illust)`):
```kotlin
_isFollowing.value = illust.user?.is_followed
_userId = illust.user?.id ?: 0
```

Add toggle method:
```kotlin
fun toggleFollow(restrict: String = "public") {
    val current = _isFollowing.value ?: return
    val userId = _userId
    if (userId == 0L) return
    screenModelScope.launch {
        // 乐观更新
        _isFollowing.value = !current
        try {
            if (current) {
                client.appApi.postUnFollow(userId)
            } else {
                client.appApi.postFollow(userId, restrict)
            }
        } catch (e: CancellationException) {
            throw e
        } catch (e: Exception) {
            // 回滚
            _isFollowing.value = current
        }
    }
}
```
